# ATS Airline Management System

## Project Overview

The ATS Airline Management System is a Java-based desktop application developed using Java Swing and MySQL database integration. The system is designed to help airline administrators manage flight schedules, routes, airports, aircrafts, offices, and users through a centralized dashboard interface.

The project uses a modern graphical user interface with dynamic database connectivity and modular system panels.
